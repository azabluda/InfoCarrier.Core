# Choose an upgrade path

| Your application | Start here |
|---|---|
| Published version 10.3 moving to development version 11 | [Upgrade from 10.3 to 11](from-10-to-11.md) |
| Version 3.1 or earlier | [Upgrade from 3.1 to 10](from-3-to-10.md), then use the version 11 guide when ready |
| A new application | [Installation](../getting-started/installation.md) and the [first tutorial](../getting-started/first-app.md) |

The ordinary guides describe the development version selected by this checkout.
Release notes describe changes at a particular release; their old examples retain their historical meaning.
Use [compatibility](../reference/compatibility.md) to plan separate client and server deployments.

Version 11 is not yet a stable published package.
See the [11.0 draft](../release-notes/11.0.md) for implemented changes and pending Entity Framework Core adoption.
