InfoCarrier.Core puts an Entity Framework Core `DbContext` on the client of a multi-tier application. This release is a rewrite for EF Core 10.

- Not compatible with `3.1.1`. Your `DbContext` and your entity classes carry over unchanged; the wiring around them does not, and old code will not compile.
- Targets `net10.0`. A .NET Framework client has to be ported first.
- No Remote.Linq and no Aqua. The expression serializer is in-tree, and the only dependency is `Microsoft.EntityFrameworkCore`.
- A transport and a server endpoint ship. `3.1` shipped neither, so every application wrote its own.
- A stated, tested security boundary on what a server will execute, with a written review.
- Verified against Microsoft's own EF Core specification suite: 22658 tests, 9 known failures, gated in CI.

```sh
dotnet add package InfoCarrier.Core --version 10.0.0-preview.1              # the client and the server
dotnet add package InfoCarrier.Core.AspNetCore --version 10.0.0-preview.1   # the server endpoint
```
