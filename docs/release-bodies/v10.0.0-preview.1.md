InfoCarrier.Core 10.0.0-preview.1 is a rewrite for Entity Framework Core 10. Your client gets a real `DbContext` with LINQ, change tracking, lazy loading and transactions, but no connection string and no database driver. Queries and units of work travel to your application server, which executes them with an ordinary EF Core provider.

```sh
dotnet add package InfoCarrier.Core --version 10.0.0-preview.1              # the client and the server
dotnet add package InfoCarrier.Core.AspNetCore --version 10.0.0-preview.1   # the server endpoint
```

It is not backward compatible with 3.1. Your `DbContext` and your entity classes carry over unchanged; the wiring around them does not.
