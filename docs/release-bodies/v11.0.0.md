InfoCarrier.Core 11.0.0 requires .NET 11 and Entity Framework Core 11.
This is a breaking upgrade from 10.3. Update configuration and rebuild both applications;
version 10 clients are not supported by version 11 servers.

- Configure clients and servers by role, with shared settings, named endpoints, and service replacement ([#253](https://github.com/azabluda/InfoCarrier.Core/pull/253), [#255](https://github.com/azabluda/InfoCarrier.Core/pull/255), [#256](https://github.com/azabluda/InfoCarrier.Core/pull/256)).
- Register extra types and anonymous shapes needed by server execution on both sides. Implicit local filtering, ordering, grouping, joins, set operations, and equality are refused; choose local work explicitly with `AsEnumerable` ([#275](https://github.com/azabluda/InfoCarrier.Core/pull/275)).
- Receive eligible non-tracking query rows progressively, including concatenated client projections ([#244](https://github.com/azabluda/InfoCarrier.Core/pull/244), [#245](https://github.com/azabluda/InfoCarrier.Core/pull/245), [#291](https://github.com/azabluda/InfoCarrier.Core/pull/291)).
- Use full joins and frozen-set filters, and preserve generated values and owned collection changes in document saves ([#283](https://github.com/azabluda/InfoCarrier.Core/pull/283), [#287](https://github.com/azabluda/InfoCarrier.Core/pull/287)).
- Update custom transports for synchronous execution, move database setup to the server, and replace removed mapping-source subclasses ([#251](https://github.com/azabluda/InfoCarrier.Core/pull/251), [#248](https://github.com/azabluda/InfoCarrier.Core/pull/248), [#291](https://github.com/azabluda/InfoCarrier.Core/pull/291)).
- Version 11.0 supports 11.0 clients only; version 10 clients are unsupported, and custom serializers must handle the updated query and result format ([#261](https://github.com/azabluda/InfoCarrier.Core/pull/261), [#274](https://github.com/azabluda/InfoCarrier.Core/pull/274)).

```sh
dotnet add package InfoCarrier.Core              # the client
dotnet add package InfoCarrier.Core.AspNetCore   # the server endpoint
dotnet add package InfoCarrier.Core.Abstractions # optional shared deployment project
```
