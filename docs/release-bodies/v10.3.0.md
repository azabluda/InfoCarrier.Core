This release makes shared client and server deployment configuration explicit.

- One application-owned method can configure anonymous shapes, allowed types, value mappers, and arbitrary SQL permission on both sides (#223).
- The new `InfoCarrier.Core.Abstractions` package carries the two shared contracts without an Entity Framework Core dependency (#223).
- Registered anonymous projections can reach the server provider, while unregistered applications keep 10.2 planning behavior (#210, #222).
- Client, server, and transport failures now produce clearer diagnostics without hiding the original failure (#217, #219).
- More query shapes match plain Entity Framework behavior, and excessively complex type descriptions are rejected before resolution (#195, #207, #213).
- Transaction responses can report uncertain outcomes, query cancellation is tested over a real connection, and 30,148 tests finish without failures (#184, #189, #223).

```sh
dotnet add package InfoCarrier.Core              # the client and the server
dotnet add package InfoCarrier.Core.AspNetCore   # the server endpoint
dotnet add package InfoCarrier.Core.Abstractions # optional shared deployment project
```
