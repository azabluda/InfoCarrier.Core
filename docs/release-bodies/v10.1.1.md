This is a patch release with one fix, and it matters to anyone not pinned to Entity Framework Core `10.0.0`.

- `10.1.0` runs only against EF Core `10.0.0`. On `10.0.1` and every later patch, a query that returns entities throws `MissingMethodException`.
- EF Core changed an internal constructor in `10.0.1`, and this provider was bound to the shape it had in `10.0.0`.
- The failure was partial, which made it hard to read: projections and scalar queries kept working, so it looked like a query bug rather than a version problem.
- The dependency is now `[10.0.1, 11.0.0)`, verified against every published EF Core 10 patch through `10.0.12`.
- If you pinned EF Core `10.0.0`, move it forward, or stay on `10.1.0`. A build error names the versions if you do neither.
- No public API changed.

```sh
dotnet add package InfoCarrier.Core              # the client and the server
dotnet add package InfoCarrier.Core.AspNetCore   # the server endpoint
```
