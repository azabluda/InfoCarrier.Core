# A test listed here is green because we assert what the store does, not because the query works.
# The list is data rather than prose so that eng/tier-d-control.py can check it BOTH WAYS:
#
#   1. A test here that the wire-free control PASSES is a suppression of something the store can
#      actually do. That is the worst failure this tier can have and the gate refuses it.
#   2. A test the control fails while Tier D passes must be here, or be a named capability gain in
#      test/tier-d-control-allowances.txt. Otherwise the control is misconfigured, or a red is
#      being hidden.
#

# unless the store's own suite says so. Upstream citations are first-best evidence; the wire-free
# control is second-best, because we wrote it and it is a conflict of interest.
