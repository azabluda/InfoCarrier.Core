# ADR-009 TIER D: where the wire-free control may fail a test that Tier D passes.
#
# Read eng/tier-d-control.py first; it says why this file exists. In short: Tier D suppresses a red
# when its control reproduces the failure without InfoCarrier, and a badly wired control fails more,
# which attributes more of our reds to the store and makes this provider look cleaner. The gate
# therefore forbids the control to fail anything Tier D passes, and every exception is named here.
#
# AN ENTRY IS A CLAIM THAT THIS PROVIDER IS MORE CAPABLE THAN THE RAW STORE. That is a strong claim
# and it needs a reason, not a name. If you cannot write the reason, the control is broken instead.
#
# Format:  <Family>.<Method>(<theory args>)   # reason

Projection.Select_untranslatable_method_on_associate_scalar_property(queryTrackingBehavior: NoTracking)   # The projection split: the server answers the translatable part and the untranslatable method is evaluated on the client, so this provider answers a query raw MongoDB refuses. ADR-010.
