# The suite is red on purpose: it inherits Microsoft's EFCore.Specification.Tests (ADR-004) and
# CLAUDE.md forbids skipping a test to force green. CI therefore gates on direction — failures
# must not rise, and the total must not shrink.
#
# Lower `failed` in the same commit as the fix that lowers it. Raise it only with a reason in the
# commit message; the last deliberate rise was step L1, which turned on the type allowlist and
# converted ~1,305 illusory passes into real M2 failures.
#
# BOTH NUMBERS ARE READ OUT OF THE TRX, not out of the console summary and never by arithmetic.
# The TRX is what eng/ratchet.sh parses, so it is the only source that cannot disagree with the
# gate. (They do agree today — `Total tests: 22312, Passed: 21950, Failed: 145, Skipped: 217` —
# but `passed + failed` is 22095, because the TRX counts the 217 skips in `total` and in neither
# of the other two. Deriving one figure from the others has cost this repo three commits before.)
